# ROS 2 Gantry Robot Simulation with MoveIt 2

This project provides a complete ROS 2 simulation environment for a 3-axis gantry robot, fully integrated with MoveIt 2 for motion planning and Gazebo for realistic simulation.

## Simulation Notes

To ensure the simulation works correctly, especially concerning object manipulation with the gripper:

1.  **Detach the ball initially**: It is crucial to detach any objects from the gripper when first starting the simulation. Keeping an object attached from the beginning might prevent the simulation from functioning as expected.
2.  **Attach the ball (if needed)**: After starting the simulation and ensuring everything is running smoothly, you can re-attach the object if your task requires it.

## Project Overview

This workspace contains the necessary files to simulate a 3-DOF gantry robot, control it using `ros2_control`, and plan complex motions with MoveIt 2. The simulation is performed in Gazebo.

The project is structured into three main ROS 2 packages:
-   `gantry`: Contains the robot's URDF description, Gazebo simulation worlds, and main simulation launch files.
-   `gantry_moveit_config_2`: The MoveIt 2 configuration package, automatically generated by the MoveIt Setup Assistant. It contains all the necessary files for motion planning, kinematics, and visualization.
-   `gantry_control`: Contains a simple C++ example of a motion planning script that uses the MoveIt `MoveGroupInterface` to command the robot.

## Robot Description

The robot is a 3-axis gantry system with a simple two-finger gripper.
-   **Joints**:
    -   `x_slider_joint`: Prismatic joint for motion along the X-axis.
    -   `y_slider_joint`: Prismatic joint for motion along the Y-axis.
    -   `z_slider_joint`: Prismatic joint for motion along the Z-axis.
-   **Planning Group**: The primary planning group for the gantry arm is named `gantry`.
-   **End-Effector**: The gripper is defined as an end-effector named `gripper`.
-   **Named Poses**: A "home" position is defined where all joint values are at `0`.

## Prerequisites

-   **ROS 2 Jazzy**: This project is built and tested on ROS 2 Jazzy.
-   **Gazebo**: Gazebo Garden (the default with ROS 2 Jazzy).
-   **MoveIt 2**: The MoveIt 2 framework for ROS 2 Jazzy.
-   **ros2_control & ros_gz**: For Gazebo simulation and controller integration.

If you have a standard ROS 2 Jazzy Desktop installation, most dependencies should be met. You may need to install the Gazebo integration packages:
```bash
sudo apt-get update
sudo apt-get install ros-jazzy-ros-gz ros-jazzy-moveit
```

## Installation

1.  **Create a Colcon Workspace**:
    If you don't have one already, create a new ROS 2 workspace:
    ```bash
    mkdir -p ~/ros2_ws/src
    cd ~/ros2_ws
    ```

2.  **Clone the Repository**:
    Clone this repository into your workspace's `src` directory.
    ```bash
    git clone <URL_of_this_repo> src/gantry_robot
    ```
    *(Note: The user should replace `<URL_of_this_repo>` with the actual URL)*

3.  **Install Dependencies**:
    Navigate to the root of your workspace and use `rosdep` to install any missing dependencies.
    ```bash
    cd ~/ros2_ws
    rosdep install --from-paths src --ignore-src -r -y
    ```

## Building the Workspace

From the root of your workspace, run `colcon build`:
```bash
cd ~/ros2_ws
colcon build --symlink-install
```

## Usage

Before running any launch commands, make sure to source your workspace in each new terminal:
```bash
# In each new terminal, from your workspace root (e.g., ~/ros2_ws)
source install/setup.bash
```

### 1. Simplified All-in-One Launch

This is the recommended way to start the simulation. It launches Gazebo, RViz, and all the necessary MoveIt 2 components in one command.

In your first terminal, run:
```bash
ros2 launch gantry_moveit_config_2 gazebo_moveit.launch.py
```
After a few moments, you should see both the Gazebo and RViz windows open and populated with the robot and environment.

### 2. Run the Motion Planning Demo

Once the simulation environment is running (using the launch command above), you can run the demo script. This command executes the `simple_move` C++ node, which uses the MoveIt `MoveGroupInterface` to programmatically move the robot to a series of predefined goals.

In a second terminal, run:
```bash
ros2 launch gantry_control move_gantry.launch.py
```
You will see the robot move sequentially in both the Gazebo simulation and the RViz visualization.

### 3. Manual (Step-by-Step) Launch

For more granular control or for debugging, you can launch each component separately.

-   **Terminal 1: Launch Gazebo**
    This command starts the Gazebo simulator, loads the world, spawns the gantry robot, and starts the `ros2_control` hardware interfaces.
    ```bash
    ros2 launch gantry gazebo.launch.py
    ```

-   **Terminal 2: Launch MoveIt & RViz**
    This command starts the `move_group` node for motion planning and launches RViz for visualization.
    ```bash
    ros2 launch gantry_moveit_config_2 moveit_rviz.launch.py
    ```
