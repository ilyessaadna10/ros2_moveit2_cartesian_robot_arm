# Project Setup and Simulation Guide

This project involves a ROS 2 MoveIt 2 setup for a gantry robot.

## Simulation Instructions

To ensure the simulation works correctly, especially concerning object manipulation:

1.  **Detach the ball initially**:  **it is crucial to detach it first** when starting the simulation. Keeping it attached from the very beginning might prevent the simulation from functioning as expected.
2.  **Attach the ball (if needed)**: After starting the simulation and ensuring everything is running smoothly, you can re-attach the ball if your task requires it.
